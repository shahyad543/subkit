Which subtitle format should I convert to?

SRT → VTT: you are embedding subtitles in a website or HTML5 player — the <track> element only accepts WebVTT. The conversion is lossless: only the header line and the comma-to-dot timestamp change are added.

SRT/VTT → ASS: you want styling — fonts, colors, outline and exact on-screen positioning that VLC and MPV honor. Converting to ASS gives every cue the same default style, which you can then tweak in a text editor or Aegisub.

ASS/VTT → SRT: you are uploading to YouTube or handing the file to a video editor. Be aware this direction is lossy: ASS override tags, positioning and styling are stripped, leaving only text and timing.

Is any file uploaded to a server?

No. SubKit's converter is a few hundred lines of JavaScript that run in your browser tab. Your subtitles are never transmitted, stored or logged — it works offline too, once the page has loaded.
