Why SubKit?

Most online subtitle converters upload your file to a server before processing it. SubKit works differently: every tool is plain JavaScript running inside your browser tab, which means your subtitles are processed 100% locally. Nothing is sent, stored or logged anywhere. It also means there is no file size limit, no queue and no waiting — a 5 MB subtitle file converts just as fast as a 5 KB one.

Which format should you use?

  • SRT — the universal choice. Upload it to YouTube, load it in VLC, hand it to any video editor.
  • WebVTT (.vtt) — the web standard. Required by the HTML5 <track> element; uses dots instead of commas in timestamps.
  • ASS — the typesetting format. Fonts, colors, positioning and effects; used by anime fansubbers and styled releases.
