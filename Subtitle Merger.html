When do you need to merge subtitle files?

The classic case is a two-part episode: you have part1.srt and part2.srt but a single continuous video. Sequential merge shifts every cue of the second file so it starts right after the last cue of the first file, with an optional gap you set in seconds. Choose overlay instead when you want two subtitle tracks with their original timings combined into one file — for example a translation written on top of original timing, or captions from two different sources.

Why split a subtitle file?

Long files are awkward to translate or proofread in one sitting, and some editors choke on subtitle files with tens of thousands of cues. Splitting into equal parts gives you manageable chunks with correct numbering in each file — pick any part from the dropdown and download it separately. If you later shift the timing of a part to match its video segment, the Subtitle Shifter does that in one step.

Which formats are supported?

SRT, WebVTT (VTT), ASS and MicroDVD inputs are auto-detected for every loaded file, and the result is exported as a clean, renumbered SRT file that YouTube, VLC and every video editor accepts. Like all SubKit tools, nothing is uploaded: your files are read locally by JavaScript in this tab and never leave your computer.
